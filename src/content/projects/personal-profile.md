## 项目背景

我希望有一个长期维护的个人主页，用来集中展示自己的项目、文章和联系方式。和直接套用模板不同，这个站点需要满足两个条件：**内容可维护**，以及**部署足够简单**。

## 主要功能

- 首页聚合个人信息、技能、精选项目、最新文章和联系方式。
- 项目管理与博客管理支持增删改，并能在后台实时预览 Markdown。
- 后台可修改个人信息、上传头像和 PDF 简历。
- 提供数据导出、导入与恢复默认，方便备份和迁移。

## 技术要点

项目使用 React + TypeScript + Vite 构建，样式基于 Tailwind CSS。默认内容存放在 TypeScript 与 Markdown 文件中，运行时修改写入 `localStorage`，头像和简历等二进制文件存入 `IndexedDB`。

为了避免纯前端方案常见的数据丢失问题，我额外设计了「默认数据 + 运行时覆盖」的合并策略：首次访问读取构建时的默认内容，后台保存后用本地数据覆盖，解析失败时自动回退，保证页面不会白屏。

## 收获

这个项目让我更系统地理解了前端数据分层、浏览器存储配额、SPA 路由回退，以及如何在没有后端的情况下设计一个可维护的内容后台。
